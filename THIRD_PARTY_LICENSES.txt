8. mbelib-neo
   Project path:
   - third_party/mbelib-neo/

   Upstream:
   - https://github.com/arancormonk/mbelib-neo

   This is an optional Git submodule. Users who need DMR voice backend support
   can fetch it with:
   - git submodule update --init --recursive third_party/mbelib-neo

   Used by:
   - optional fobos_dmr_voice_mbelib backend
   - internal DMR voice fallback when FobosAPP is built with
     FOBOS_ENABLE_MBELIB_NEO=ON

   License: GNU General Public License version 2 or later.
   Local license and notice files in release packages:
   - licenses/dmr_voice_backend/mbelib-neo-LICENSE.txt
   - licenses/dmr_voice_backend/mbelib-neo-README.md

9. OpenDMR / softdmr
   Project path:
   - third_party/softdmr/

   Upstream:

   Used by:
   - optional fobos_dmr_voice_opendmr backend

   License: GNU General Public License version 2.
   Local license and notice files in release packages:
   - licenses/dmr_voice_backend/softdmr-LICENSE.txt
   - licenses/dmr_voice_backend/softdmr-README.md

10. OP25 MBE encoder-derived code
   Project path:
   - third_party/softdmr/encoder/

   Used by:
   - optional fobos_dmr_voice_opendmr backend

   The OpenDMR/softdmr tree contains encoder code derived from OP25
   MBEEncoder work. Preserve upstream source headers, attribution comments,
   and the softdmr GPL license when distributing source or binaries that use
   this backend.

Release/source obligation note:
If a binary release includes GPL DMR voice backend DLLs, publish the
corresponding FobosAPP and FobosDMRVoiceBackend-gpl source, plus the exact
mbelib-neo and softdmr/OpenDMR source revisions used to build those DLLs, or
provide an equivalent GPL-compliant source offer.
